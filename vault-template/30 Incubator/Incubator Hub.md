# Incubator Hub

## Purpose
Possibilities for later, visibly separate from commitments. One substantive idea per note. Use properties for type and lifecycle instead of many empty status folders.

## Read and write rules
Use [[99 System/Templates/Idea Template]]. Preserve original intent, evidence, uncertainty, and smallest useful next step. Promotion requires a real decision: link the resulting Project or Area and preserve the idea as history. Do not treat an agent suggestion as adoption.

## Current entry points
No user ideas are configured. A Base is optional only once repeated records justify it.
