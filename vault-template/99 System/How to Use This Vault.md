# How to Use This Vault

1. Capture unclear material in Inbox.
2. Keep current responsibilities in Areas and finishable work in Projects.
3. Save possibilities in Incubator and reusable knowledge in Resources.
4. Keep history in Archive and operating rules in System.
5. Start with the Hub for the subject. Follow its useful reading order.
6. Preserve a source once and link it. Record why decisions changed.
7. Review Inbox and active outcomes at a realistic cadence you choose.

An agent can carry formatting and metadata work. You do not need to memorize schemas to write a note. If the agent asks a question already answered in the vault, direct it back to the relevant source.

## Give a new agent the entry point
Read [[99 System/Agent Onboarding]] and supply the private local root plus its compact bootstrap. A chat session without access cannot edit the original vault. No automatic sync, backup, or review schedule is installed here.
