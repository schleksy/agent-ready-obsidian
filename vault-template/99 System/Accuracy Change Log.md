# Accuracy Change Log

## Purpose
Record verified corrections and unresolved discrepancies. Preserve the reason, authority, scope, old state, successor, and meaningful follow-up. Never include secrets.

## Entry format

```text
### YYYY-MM-DD - Short description
- Status: corrected | review-needed | merged
- Affected notes:
- What looked wrong:
- Verified source and actual claim established:
- Action taken:
- Supersedes / successor:
- Validation:
- Remaining dependency:
```
