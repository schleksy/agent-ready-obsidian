# Agent Onboarding

## First entry
Read [[AGENTS]], [[Vault Hub]], and [[99 System/Rules/Operating Contract]]. Establish your actual access mode. Read [[99 System/Rules/Platform Onboarding]] for the persistent bootstrap and fresh-session test.

## Short-command router

| Request | Required route |
| --- | --- |
| Organize inbox | [[00 Inbox/Inbox]], [[99 System/Rules/Capture Workflow]], then [[99 System/Rules/Routing and Maintenance]] |
| Organize a subject | Whole-vault identity search, relevant Hub chain, then routing and maintenance |
| Add or create | Search canonical copies, establish ownership/lifecycle, read destination Hub/template, register and verify |
| Capture | Capture workflow; report the actual receipt state |
| Find or research | Read-only retrieval through relevant sources unless a write was requested |
| Refresh data | Preserve old snapshot, read source guide, add dated evidence, reconcile current summary |
| Audit or clean | Inspect first; validate claims and respect broad/destructive boundaries |
| Build | Relevant subject Hub and adopted [[99 System/Rules/Build Workflow]] |
