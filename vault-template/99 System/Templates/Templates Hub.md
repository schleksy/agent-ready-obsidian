## Purpose
Reusable formats. Choose a real need and replace tokens; do not instantiate every template by default.

## Creation rules
Read the destination Hub and search existing notes first. Set the nearest governing `hub:`, correct lifecycle, date, evidence, and supported relationships. Templates cannot assume an owner, approval, or active state. Register created notes and validate links.
